# Security Policy

This repository is a fork of [AI-Riksarkivet/htrflow](https://github.com/AI-Riksarkivet/htrflow),
used as an integration/testing branch (`qa`) before changes go upstream.

## Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities. Instead:

- Use GitHub's [private vulnerability reporting](https://github.com/andy778/htrflow/security/advisories/new)
  for this repository, or
- Email the upstream maintainers at ai@riksarkivet.se.

Include a description of the vulnerability, steps to reproduce, and its
potential impact. We'll acknowledge reports as soon as possible.
